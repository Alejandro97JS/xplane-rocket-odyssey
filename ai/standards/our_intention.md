We want to build an interactive game playable from the browser, solving ai/standards/statement.md. We want to deploy it and make it available via Railway. You can choose the stack you want, the best possible for the case. I also want a configuration setup for local development, so we can test the game in localhost.

For example, in the use case 1 we want to focus on the launch of a rocket. There are a few initial steps (screens) where the user interacts adapting the input parameters. Then, there is a final step that is "Launch!", where it is deployed a simulation of the launch according to the aim of the mission and according to the parameters given by the user. We want the simulation to be realistic, failing if the parameters were wrong and succeeding if they were ok.
