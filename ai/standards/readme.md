# README and its screenshots

The project owner set these rules on 2026-11-15. Follow them. Changing them needs the owner's approval.

## Rules

1. When a screen of the game changes, update the `README.md` at the root of the repository wherever it describes that screen or what happens on it, if the change affects what it says.
2. When a screen of the game changes, capture again the screenshots in `docs/screenshots` that show that screen, if the change affects what they show, so the README always shows the game as it is.

## How

What each image shows, the design and the moment it was captured with, and how it was captured are recorded in `ai/self_documentation/readme.md`. Capture a replaced image the same way, so the set stays consistent, and record any change there.
